Review uncertain voices

Confident matches are already assigned. Choose people for uncertain groups, then correct any exceptions.

Assigning a speaker fixes the transcript. Training uses only the suitable clips you approve; a short clip never blocks saving a person.

How to apply this review

Export downloads a decision file. Apply it on the machine with the original project using this command. If your downloads folder differs, change the path.

This offline page cannot change the transcript directly. Import lets you continue a saved review before applying it. Regenerate pages with ./transcribe-media --review-speakers after applying or updating the app.

People & profile labels
